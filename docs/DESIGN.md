# PixivBatchBookmark Windows v1.0 设计

目标：Windows 10/11 x64 桌面程序，使用用户确认的狐耳女孩竖图作为背景、小女孩方图作为图标，处理插画、漫画和动图的作品 ID。

## 项目边界

- Python 3.12 + PySide6；Qt WebEngine 内置浏览器登录真实 Pixiv 网站。
- 使用 Chromium 独立持久化配置保存会话，不在源码或日志中保存账号、密码、Cookie 或 CSRF token。
- 支持纯数字 ID、Pixiv 作品链接、`pixiv id：123` 混合文本；去重并保留首次出现顺序。用户链接和小说链接不当作作品 ID。
- 用户选择公开/私密收藏；同模式跳过；不同模式按要求先取消再收藏，并尽力恢复失败的转换。
- 批量取消仅处理用户输入的作品，执行后查询确认。
- 主界面、登录窗口、TXT 导入、剪贴板粘贴、暂停/继续/停止、日志及结果导出；HTTP/SOCKS5 代理适用于内置浏览器和接口。
- 无账号时只做本地解析与离线验证，不声称已完成真实账号测试。

## 结构与数据流

`pixiv/parser.py` 负责输入解析。`pixiv/bookmark.py` 是无 GUI 依赖的生成器式业务流程，每一步产出明确的 Request，接收已解析的响应或 ApiError。`pixiv/browser.py` 使用共享浏览器配置，通过隔离 JavaScript 世界中的 WebChannel 返回同源 fetch 结果。`ui/controller.py` 用 Qt 定时器串行调度；`ui/window.py` 展示输入、操作和结果。

每次请求之间默认间隔 1.2 秒。停止和暂停在作品边界生效，当前作品的转换/恢复必须先完成。登录失效、拒绝访问、限流、状态无法确认时停止后续作品。POST 不盲目重试；响应丢失时先查询最终状态。

## 数据保护

转换前读取原收藏标签/备注；读不到所需结构时不删除。取消收藏成功后，重建失败则先查询确认，再按原模式与标签恢复。恢复失败明确报告“状态需人工检查”。转换会产生新的收藏记录，无法保留原收藏时间/ID。

原图保留在 resources/originals。背景按比例铺满，界面覆盖半透明浅色面板。图标使用完整方图，转换为 PNG 和多尺寸 ICO，保留原图内容。

## 验证

标准库 unittest 覆盖解析、状态读取、收藏/取消/转换、丢失响应、恢复与异常结构。Qt 离线集成测试使用本地 HTTP fixture 测试实际 Chromium fetch/WebChannel/CSRF 头/表单/超时与 GUI。最后实际运行 PyInstaller，启动构建产物并检查资源和界面。
