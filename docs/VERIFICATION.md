## 修复并验证的失败路径

- 刷新登录时立即使旧登录状态失效，避免在 CSRF token 刷新过程中开始写入。
- 写入得到 401/403/429 或其他强制停止错误，即便最终状态核验成功，也停止后续作品。
- 转换删除阶段或恢复阶段遇到限制时，保留停止标记；已确认取消的原收藏先尽力恢复。
- 元数据页缺少标签/备注字段时，不取消原收藏。
- JSON null/数组/非对象等未知接口结构明确停止队列。
- 暂停/继续与排队回调重入时，不替换正在执行的作品流程。
- 首次安装依赖中断后，run.bat 会检测并重新安装缺少的模块。
- 本机构建环境的 Poppler ICU DLL 与 Qt 所需 Windows ICU API 不兼容；构建配置排除冲突 DLL，由 Qt 使用 Windows 系统 ICU。没有修改系统库或全局 PATH。Windows 自带 ICU 的背景见 [Microsoft 官方文档](https://learn.microsoft.com/en-us/windows/win32/intl/international-components-for-unicode--icu-)。
